Selected work

Selected work · Grocery network

The network had motion.
It needed a clock.

A regional grocery system that could fill a truck and still miss a store. The work was not more activity. It was one rhythm the whole network would obey.

01 · Mandate

Hold service without buying it twice

Keep shelves honest and cost honest on the same week. In-stock as a standard, not a rescue. Inventory as a consequence of the plan — not a substitute for one.

02 · Constraint

Every node ran its own week

Stores ordered against noise. DCs chased the last fire. Planners lived in exception. The weekend became the real operating system, and the official one became theater.

03 · System

One cadence. One definition of full.

A single weekly clock from forecast to floor. Named owners. Exceptions only — never a second system. If it could not be seen on Monday, it did not exist.

04 · What held

The weekend stopped being the plan

Service recovered without using inventory as camouflage. The network still moved. It finally moved on purpose.

Authority is earned in the details.
